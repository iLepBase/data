# iLepBase data processing

Data processing and quality control scripts, filtered and cleaned data tables for iLepBase.

This initial snapshot preserves the original `script/` directory layout and processing logic. See `script/README.md` and module-specific README files for workflow details. Paths in the original scripts may require adjustment to the local data layout.

Virtual environments, Python caches, request-cache databases, execution logs and the external NCBI datasets binary are excluded. Embedded NCBI API keys in three script copies have been replaced with the `NCBI_API_KEY` environment variable. No license is assigned by this upload.
