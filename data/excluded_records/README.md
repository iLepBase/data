# Excluded records

`transcriptome_excluded_218.csv` lists 218 transcriptome metadata records excluded when reproducing the species-linked dataset of 20,156 records from the original 20,374-row table. Original columns are retained, with the source CSV row number and exclusion reason added.

| Exclusion reason | Records |
| --- | ---: |
| Missing valid Run ID | 12 |
| Unmatched taxonomy | 206 |

The taxonomy-unmatched records comprise 119 records labelled only at higher taxonomic ranks, 71 unidentified or provisional taxa, 12 records labelled as Cordyceps militaris, and four records labelled as Nymphalis c-aureum that were not resolved by the mapping table used for this audit. An unresolved name does not imply an invalid name or poor sequencing quality.
